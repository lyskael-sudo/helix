# 🚀 Helix - AI Code Agent

**Helix** is a powerful AI-driven CLI tool for code generation, explanation, optimization, bug fixing, and language conversion. It runs locally using **Ollama** with **Mistral** and **Llama2** models.

## ✨ Features

- 🤖 **Generate Code** - Create code from natural language descriptions
- 📝 **Explain Code** - Understand code with AI explanations
- ⚡ **Optimize Code** - Improve performance and readability
- 🐛 **Fix Bugs** - Debug code with AI assistance
- 🔄 **Convert Languages** - Translate code between languages
- 🎨 **Colorful CLI** - Beautiful terminal interface
- 💾 **Auto-Save** - Save results to files
- 🔀 **Multi-Model Support** - Switch between Mistral and Llama2

## 🛠️ Supported Languages

- Python
- JavaScript / TypeScript
- HTML / CSS
- C / C++
- Java
- Go
- Rust
- SQL
- Bash
- And more!

## 📋 Requirements

- **Python 3.8+**
- **Ollama** ([Download](https://ollama.ai))
- **Internet connection** (for initial model downloads)

## 🚀 Quick Start

### 1. Install Ollama

Download from [ollama.ai](https://ollama.ai) and install for your OS.

### 2. Download Models

Open a terminal and pull the models:

```bash
ollama pull mistral
ollama pull llama2
